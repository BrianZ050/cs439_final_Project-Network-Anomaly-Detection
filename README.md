# Unsupervised Network Anomaly Detection (CICIoT2023)

This repository contains an advanced **Unsupervised Machine Learning** pipeline designed to detect zero-day network intrusions using the **CICIoT2023** dataset. 

Instead of relying on supervised signatures, this pipeline trains mathematical models (like Local Outlier Factor and Isolation Forest) exclusively on normal, benign network traffic. The models learn the mathematical boundaries of a "normal day in a smart home" and flag any deviations as anomalies.

This approach was proven highly effective at detecting 33 distinct classes of modern IoT attacks, ranging from massive DDoS floods to stealthy application-layer exploits.

## Quick Start

Run the full unsupervised training pipeline. This will load the `CSV/` directory, map the labels, train the models on Benign traffic, and evaluate them on a mixed test set.

```powershell
.venv\Scripts\python.exe train_ciciot_unsupervised.py --data-dir CSV --output-dir artifacts/ciciot_unsupervised_run
```

*Note: The default is **20,000 rows per class**, which is safe for 16 GB of RAM and finishes in **under 1 minute**. You can override this with `--max-rows-per-class <N>`. Some rough timing estimates on a 16 GB machine:*

| `--max-rows-per-class` | Approx. Runtime | RAM Usage |
|---|---|---|
| `5000` (smoke test) | ~10 seconds | Low |
| `20000` (default) | ~1 minute | Safe |
| `50000` | ~5 minutes | Moderate |
| `220000` | ~1 hour | High |
| `500000` | ~5 hours | Very High |
| `0` (no limit, ~47M rows) | Days | Will crash on 16 GB |

*Set to `0` to load the **entire dataset** with no limit — not recommended on machines with less than 32 GB of RAM.*

Generate the academic visual plots (ROC Curves, PR Curves, and Class Detection Rates):

```powershell
.venv\Scripts\python.exe artifacts/plots/generate_visualizations.py
```

## Dataset (CICIoT2023)

**Note to Evaluators:** Due to GitHub's strict file size limits (100MB per file), the multi-gigabyte dataset could not be uploaded to this repository. To run this code locally, you must first download the dataset:

1. Download the dataset from the official [CICIoT2023 Canadian Institute for Cybersecurity page](https://www.unb.ca/cic/datasets/iotdataset-2023.html)
2. Extract the data.
3. Place all 34 folders (e.g., `Benign_Final`, `DDoS-ICMP_Flood`, etc.) into a folder named `CSV/` in the root of this repository.

The dataset consists of 34 folders (1 Benign and 33 Attacks). The benign traffic was generated by a real-world laboratory topology containing 105 physical IoT devices (smart hubs, cameras, sensors).

The pipeline automatically identifies the `Benign_Final` folder as `0` and all other folders as `1` (Anomaly). 

Because the dataset utilizes pre-extracted flow meter statistics (39 continuous features like `Variance`, `Tot sum`, `IAT`), no manual feature engineering is required.

## Methodology

1. **Strict Benign Training**: All malicious traffic is explicitly deleted from the training split. Models are only allowed to see `y == 0` during training.
2. **Zero-Day Evaluation**: Models are tested against a hold-out test set containing normal traffic mixed with 33 zero-day attacks they have never encountered before.
3. **Thresholding**: A 95th percentile threshold on the benign training scores is used to convert continuous anomaly scores into binary classifications.
